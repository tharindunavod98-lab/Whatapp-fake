# Relay: encrypted push-to-talk

1. Make a free project at supabase.com. No tables needed; Realtime Broadcast only.
2. Settings > API: copy the Project URL and the anon public key.
3. Open index.html, paste them into CFG near the end of the script (or type them once in the app).
4. Host the folder on GitHub Pages (HTTPS is required for mic, GPS and install).
5. Both phones open the page, enter the same channel and passphrase, then Add to Home Screen.
